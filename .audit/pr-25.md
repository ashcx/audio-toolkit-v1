## Why
Sprint 25 cuts repeated metadata, makes original, processed and exported audio obvious, and gives Export one clear action row.

## What changed
- Rows show filename and duration only. A changed Trim all range adds one line. The per-file trim override path is removed.
- Original playback appears after intake. Preview appears only with a non-empty recipe and no current export. Export and previous export use direct players, one-at-a-time playback and a download icon bound to the same output.
- Export status is left; Clear all, Save to device and Export are right. Clear all cancels work, keeps the visible recipe/export preferences, releases temporary outputs and leaves saved downloads.
- Trim is one shared rule named Trim all.

## Scope
Sprint 25 only. No waveform handles, encoding modes or LUFS/compressor work. Save to folder is unchanged and not re-exercised. WebKit, physical devices and listening are not claimed.

## Tradeoffs
- Removed the per-file override path entirely because no persisted state can restore it. Sprint 29 reintroduces individual trimming through waveform handles.
- `Clear results` remains inside Save to device as a distinct action; Clear all is the new top-level action.
- Clear all freezes the visible automatic stream-copy choice so the setting does not change under the user.

## Blast Radius
Touches the file list, trim step, preview gating, export footer and Clear all lifecycle. Source files and saved downloads are never deleted.
