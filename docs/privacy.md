# Privacy and temporary storage

The application reads selected File objects locally and processes media in this browser. There is no app upload endpoint or telemetry integration. Tools, codecs, models and WASM download as static assets from the app origin when needed. The isolation model is 85 MB, fetched from the app origin on first use. The browser may reuse its cached copy, but the app sets no cache headers, so reuse is not guaranteed, and every job re-verifies the model's hash. The static hosting provider receives normal asset requests and connection metadata. Local-only media processing does not mean network-free startup.

The privacy driver observes real voice inference and ZIP creation in Chromium/WebKit, asserts static GET requests under the same-origin base path plus local object-URL reads, with no bodies or source filenames, checks lazy model loading and served notices, and reloads the workspace. This establishes the observed flows only; it is not a proof about browser extensions, the hosting provider or every possible browser implementation.

Output files and processing checkpoints use origin-private browser storage. In-memory file identities, step settings, results and object URLs belong to this tab. Remove, Discard exports, Clear all and normal cancellation release owned files; a cleanup that fails twice shows one message with Try again and blocks new work that would lose ownership. ZIP has separate ownership and cannot discard successful media results after failure.

Theme preference is stored in localStorage. No media, filenames or step settings are deliberately stored there. Closing/reloading does not restore jobs or downloads. A forced close, crash or mobile process kill may interrupt asynchronous cleanup and leave temporary storage behind. The app does not delete unknown files that might belong to another open tab. To remove all origin data after closing app tabs, use the browser's site-data controls for this origin; that also affects other apps sharing the origin.

The header links to the tools hub and Settings links to licenses. Navigation to those external pages follows normal browser behavior; sibling apps are outside this app's processing/privacy evidence.

Save to folder is optional and capability-dependent. It asks for a local directory through the browser and writes completed outputs into a new batch subfolder. No directory handles are deliberately persisted, uploaded or reused across sessions. Completed saved files remain in the chosen folder after Clear results or closing the tab. Cancellation stops further files; a failed write attempts to remove only its own partial file, and any cleanup failure reports that path. It does not remove existing user files or prior successful saves. A browser or process crash may leave a partial/empty batch folder. Individual/ZIP downloads remain available when folder access is unavailable, denied or cancelled.

Opening Gain or Normalize measures selected original audio locally in a worker. Peak/average RMS summaries are held in memory and successful results are weakly cached by immutable File object for this tab. Closing the step, changing files or starting export cancels active analysis. Measurement does not upload media, persist statistics or run neural models.
