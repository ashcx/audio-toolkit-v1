# YouTube speech fixtures

The user authorized YouTube sample downloads on 2026-10-30. Two complete small audio tracks were downloaded locally. Their exact hashes, original titles, authors, source URLs, license evidence and transformations are in youtube-fixtures.json. No source audio or signed media URLs are committed. The yt-dlp metadata lacks a license value for Orton, while Deverell reports Creative Commons Attribution with reuse allowed. The Commons records provide separately recorded attribution evidence. This does not infer reuse rights merely because a video is public.

The Green Interview's David Orton interview is linked as the source of the full Commons video at https://commons.wikimedia.org/wiki/File:David_Orton,_The_Green_Interview.webm . That page records CC BY 3.0 and The Green Interview attribution. The Tamara Deverell interview is linked as the source of https://commons.wikimedia.org/wiki/File:Tamara_Deverell_during_an_interview,_March_2022.jpg . The Commons page identifies Lyn Fairly Media and the YouTube CC BY template. Its original page source was retrieved through the Commons API and retained locally. Unlike the Orton record, that Commons item is a still extracted from the video, so its source-level license evidence is less direct. Keep this limitation visible in any later distribution audit.

Run `node scripts/prepare-speech-evaluation.mjs` for pinned research runtimes. With yt-dlp installed, run `node scripts/prepare-youtube-speech.mjs` to fetch and verify the two audio tracks. Set YT_DLP to an absolute executable path if necessary. This script performs network calls and is not part of deterministic normal tests. Changed audio hashes fail verification instead of silently replacing prior evidence. Downloaded M4A bytes may change if YouTube re-encodes a source.

Copy scripts/speech-youtube-evaluation.html to .artifacts/youtube-evaluation.html. Serve .artifacts at localhost, then open /youtube-evaluation.html in Chrome and select Evaluate excerpts. Each recording must contain the entire 30–50 second interval. Chrome performs decoding and mono resampling. No system audio-tool installation is required. The locally installed FFmpeg executable could not execute on this Mac, so partial-download attempts were abandoned before successfully downloading complete audio-only tracks.

The data shape is a source/condition/model/run table. Each source has its original condition and a separate deterministic added-white-hiss condition. Each condition runs GTCRN and DeepFilterNet3 alternately five times. Hiss energy is set 5 dB below the original recording's total energy, not below a known isolated speech track. The random generator is seeded identically per case; the noise waveforms differ across model sample rates. This is not a controlled perceptual comparison between sample rates or a clean-reference SNR evaluation.

Every model run pads the last frame, flushes at least the assumed algorithmic delay, removes that delay and checks finite, changed, nonzero output with exactly the input frame count. The 256-sample GTCRN and 1440-sample DeepFilterNet3 offsets come from the earlier reference experiment. Alignment is assumed here because these interviews have no clean reference. Frame counts do not prove undamaged consonants or tails. Clipping is counted before WAV download clamps to PCM16. Delay correctness, natural noise reduction, intelligibility and audible artifacts need listening observations.

The page provides labeled playback and WAV downloads for inputs and both models from the first repeat. These are local audition artifacts. No listening session has been claimed. Decode/resample, model initialization and inference are included in elapsedMs; source fetching/decoding happens once per source before repeated processing and is excluded, as are subsequent downloads. These timings are diagnostic only. Peak memory and a profiler-derived limiter are still unmeasured. Whole short-source decode and audition buffers make this a research page, not a bounded application implementation.

The final Chrome record contains 40 completed runs, zero model errors, matching input/output sample counts and zero pre-encoding clipped samples. Output quality and natural recording noise characteristics have not been listened to or classified. The two interviews broaden source coverage but do not establish a representative noise corpus.

The preparation script verifies each temporary download before promoting it to the fixture path. On mismatch, it preserves any existing fixture and removes the temporary directory. `node --test tests/speech-fixtures.test.mjs` verifies both mismatch recovery and successful promotion with an isolated fake downloader, without network calls.
