# S07-US01 MP3 and AAC

Main instance implementation extends the single terminal encoder in the existing ordered PCM worker. Format descriptors supply matching filename extension and MIME. MP3 uses pinned LAME WASM with an explicit constant bitrate. AAC-LC prefers suitable native capability; observed WebKit native timing/tail defects make that measured path unsuitable, so WebKit uses the rebuilt fallback. Chromium Linux also uses fallback because native AAC is unavailable. Successful native AAC on other platforms remains NOT VERIFIED and is not inferred from capability APIs.

All advertised MP3 128/192/256/320 and AAC 128/192/256 kbps controls are independently exported and decoded. Initial 96-check matrix covered all bitrates at 48kHz, all legal rates at128kbps, mono,30-second and481-frame tails in both engines. Full legal bitrate/rate/channel Cartesian validation passed224 downloads; it expands the initial acceptance cases because low-rate codecs can silently cap excessive bitrate. The planner now rejects those illegal settings and permits recovery; it does not silently change requested rates or bitrates.

The finalized MP3 Xing metadata excludes the muxer's metadata frame and records LAME's encoder delay/tail padding. FFmpeg now returns exactly the selected PCM frame count, including non-frame-aligned and very short inputs. AAC preserves source head/tail and zero presentation start while its final packet may include up to1023 padding samples. Audio tolerances and scope are in architecture.md.

The unpinned original AAC binary is replaced by a locally reproducible FFmpeg n8.0 build. Its exact source revision/archive, retained wrapper/bridge/worker, compiler version, rebuild recipe and artifact hashes are committed/served. Dedicated rebuilt-AAC matrix passed18 downloads; later96-check matrix used that runtime. A complete rebuild script and repeated artifact-only builds produced identical manifests. This closes the specific missing FFmpeg source-revision/build artifact gap, without claiming all transitive audit work complete. See vendor/aac/README.md, provenance.json and aac-*.txt/json.

Self-review corrected native AAC duplicate timestamps and then rejected its incomplete tail, rather than accepting a superficially aligned head. No abandoned native priming-source patch remains. Independent integrated review passed; see interrogate.md.
