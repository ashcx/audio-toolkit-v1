# S07-US02 WAV, FLAC and Opus

WAV remains PCM16 RIFF. Known oversized WAV recipes fail during planning, with trim/rate/channel recovery proven in planner tests; the same byte guard runs during actual encoding before overflow. Boundary tests cover the exact mono/stereo frame cutoffs. Large real resource limits remain Sprint11, not inferred from arithmetic checks.

FLAC uses pinned libFLAC WASM and documents24-bit terminal PCM. Independent FFprobe observes24 bits and exact rate/channels; decoded PCM error stays below the frozen24-bit tolerance on unchanged-rate reference signals. No whole-file encoded output buffer is used.

Opus is encoded natively in OGG at64/96/128/160/192kbps. Source PCM may be16/24/48kHz; Opus decoding uses its mandatory48kHz clock. Unsupported44.1/32kHz requests fail clearly until an explicit recipe rate change. Both engines flush one extra silent encoder quantum; bounded final-page packet selection, final granule, checksum and owned-store truncation remove encoder padding from the audible result. No silent tail is appended to playback.

The first last-page-only rewrite failed when a previous page had already crossed the intended end. The corrected implementation retains at most four bounded pages and removes padded packets/pages after the actual end. Chromium lower-rate Opus also reports pre-skip in input-rate units; a narrow correction to its known312-sample default is applied to the finalized container header. Changing metadata before the muxer was rejected after it changed the first-page clock; final container correction preserves packet clocks. Dedicated Opus checks passed18 downloads across both engines, then all96 initial format checks passed, including481-frame files and rate rounding. Lossy reference tests check complete head/tail signal and duration, rather than trusting only headers.

Storage adds one typed truncate operation while preserving main ownership and cleanup. The browser harness injects a truncate failure, requires no retained output, then verifies retry/removal. Independent integrated review passed; see interrogate.md.
