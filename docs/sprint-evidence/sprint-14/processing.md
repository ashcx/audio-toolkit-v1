# Streaming speech candidate

The PCM worker creates lazy per-channel states. Standard fetches the GTCRN runtime/model asset from this build's own origin; Detailed does the same for the compiled DeepFilterNet3 runtime. Source PCM resamples to model rate, buffers one model frame per channel, compensates observed latency and flushes zero padding before returning to the original rate. Two held output blocks allow exact final-grid correction with the original source clock. A single terminal encoder remains owned by the existing worker. There is no full-recording analysis/checkpoint for speech.

Tests use delayed reference processors to prove the adapter mathematically, including stereo channels with different source signals and arbitrary decoder block boundaries. Cancellation in production terminates the entire PCM worker through the existing processAudio abort path. The unit test additionally proves orderly release when the adapter observes an aborted signal. Empty input creates no model. Resource claims are limited to adapter PCM buffers; compiled model peak memory is not measured and remains an open factual gate.

Detailed model package/source identity and notices are recorded in THIRD_PARTY_LICENSES.md. The original model owner's pretrained-weight redistribution clarification and compiled Rust transitive-notice audit remain open. No deployment or full licensing acceptance is claimed. User-authorized local evaluation and review continue while those release questions remain explicit.
