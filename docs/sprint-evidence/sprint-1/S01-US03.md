# S01-US03 preliminary verification contract

Status: In progress. Use repository-generated synthetic PCM as the deterministic fixture baseline. A 1-second 440 Hz mono sine at 44.1 kHz and 0.2 amplitude is created locally. It contains no private or licensed third-party recording. Expand with silence, stereo independent channels, long tones and impulses before DSP acceptance. Real music/live listening fixtures require lawful user material or identified redistribution rights.

Lossless output acceptance will require exact selected sample rate/channel count, finite samples and duration within one sample where the processing contract allows it. Peak normalization tolerance is 0.1 dB. Gain amplitude tolerance is 0.1 dB away from clipping. Lossy codec duration comparisons must account for documented encoder priming/padding and compare decoded effective audio, not naive container duration equality. Preliminary smoke tests only check valid decode and positive duration; they do not yet prove those DSP tolerances.

Early capability probes use pinned automated Chromium and Linux WebKit. These are not observations of Edge, macOS Safari, iOS Safari or Android hardware. User authorized deferring physical-device checks to final acceptance. Minimum OS/browser versions remain provisional until capabilities and actual device observations establish the supported matrix. No maximum file size, batch count or unlimited/background execution guarantee is asserted.

Initial acceptance candidates, to be confirmed on real devices at Sprint 12: Chrome/Edge 144 or later on Windows 11/macOS 14 or later; Safari 18.4 or later on macOS 14 and iOS/iPadOS 18.4 or later; Android Chrome 144 or later on Android 12 or later. These are test targets, not claims of passing support. Linux automated Chromium 156 and WebKit 27.2 are the present observed engines. Freeze recipe defaults from orchestration; numeric PCM tolerances above are the downstream test contract. Real-world workloads and device observations can narrow measured supported limits before release, without silently dropping initial required capabilities.

Inspection references are the known generated PCM source, independent encoded-file demux/decode (separate Input/AudioSampleSink after conversion), explicit lossless sample count and finite-value checks, and WebKit's independent codec implementation. These are feasibility checks; independent external DSP-reference measurements remain Sprint 6/7 work. Copy packet equality and zero-codec instrumentation remain Sprint 5 acceptance rather than being claimed by `copy.valid` here.

The user explicitly authorized synthetic early isolation feasibility with real lawful music/live listening deferred to the isolation sprint before final acceptance. The listening rubric for that gate must cover intelligibility/voice retention, instrumental leakage, transient retention, chunk boundaries, tails and distortion in both modes. Compare the same input at matched playback level, retain lawful fixture provenance, record actual listener observations and keep unavailable outcomes NOT VERIFIED. Numeric continuity budget is no missing/repeated source frames and overlap reconstruction residual below 1e-5 for a synthetic perfect-reconstruction control; model quality cannot be established by sine-wave finiteness. This early waiver does not remove actual Sprint 9/12 listening evidence.
