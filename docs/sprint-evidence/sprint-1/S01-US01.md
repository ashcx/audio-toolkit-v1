Actual architectural grounding: source files become a Mediabunny Input, which probes the primary audio track. Conversion produces an audio-only output through a native or registered WASM encoder. The app will own serializable recipe data, effective file snapshots, planner, bounded PCM stages, job attempts and result storage. Libraries own container parsing, codec operations and model math. No frontend binding to library internals is required.
