# Implemented isolation experiments

`processAudio` accepts optional diagnostic isolation settings. Normal callers continue to use 11 second windows,50% overlap and a fresh worker for each window. The overlap option changes both reflected edge padding and the streaming hop, and progress uses the same geometry as reconstruction. Supported values are 50% and 55%, with invalid values rejected before inference. The model-input maximum remains 485100 samples.

The experimental worker lifetime is one or two completed windows. A retained worker keeps one ONNX session between two sequential calls, with CPU arenas and memory-pattern caching disabled. The runner terminates that worker after the second successful call. It also terminates active and idle workers on cancellation, terminates a failed GPU worker before one sticky CPU retry, and preserves the existing initialization/inference deadlines. Actual session/worker loads are reported separately from attempted inference calls. The vendor wrapper no longer frees the session after each separate() call. Its lifetime is owned by the runner terminating the worker after one default call or two experimental calls. The original worker also invoked session.free() before posting completion. No global session cache, shared model worker or unbounded lifetime is introduced.

The model graph remains unchanged. Its actual input metadata is `[1,4,2049,476]`. The direct shape probe confirms that 15 second and 22 second input time axes are rejected by ONNX Runtime. The streaming implementation therefore does not relabel larger outer buffers as larger neural inference windows.

`prepare-isolation-experiment.mjs` builds a separate local production bundle and verifies the existing lawful fixture hashes. `isolation-experiment-check.html` drives the actual `processAudio` path and validates each decoded export. `summarize-isolation-experiment.mjs` checks completeness and correctness before printing statistics. `sample-isolation-host.py` records Chrome CPU/RSS without claiming ownership of the user's other tabs.

Model licensing and quantization are unchanged. A higher-precision or replacement model is outside this finite window/session experiment. The user's reported distracting passages have not been supplied as a controlled evaluation excerpt or independently classified by listening, so this work does not claim their artifacts are fixed.
