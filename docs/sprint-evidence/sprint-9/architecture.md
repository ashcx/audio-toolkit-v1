Candidate A calls the verified separate() API on bounded windows, reusing one session and overlap-adding outputs. ## Frozen processing contract

Consume input once, counting original frames and preserving first source time, rate and channels. Spool original-rate float PCM to owned OPFS while computing model-rate global mono-reference mean/variance through the bounded sinc generator. Skip resampling when the rate already matches44100Hz. Seal to a PcmReplay.read() factory over an immutable File, so model inference and original subtraction have independent readers. Decode occurs once.

Replay/resample standardized samples using global statistics. Inference workers request only vocals with standardize false. Each uses one fixed485100-frame model window, then is terminated by main. The PCM worker applies242550-frame hop,48510-frame linear fades and weighted overlap-add, reflecting long source ends as upstream and trimming that context afterward. Retain only fixed head/tail/window/accumulation buffers. Emit at most4096-frame blocks.

Restore voice to original rate/channel count. Hold two final PCM blocks to correct double-rounding to exact input frame count, including correction across a block boundary. Keep voice emits that stream. Keep music subtracts it from an independent original PCM replay, retaining source bandwidth above the model band. Preserve source-time origin so later trim still uses the original coordinate system. Discard unrequested model output and the spool after use.

Batch gives isolation an exclusive job slot for its entire analysis/model/encoding/cleanup lifetime. This conservative policy follows the model's near2GiB measured footprint; no ordinary conversion job runs beside it yet. Non-isolation batches retain capability-based one/two processing slots. Sprint10 preview must reuse this owner. One bounded inference RPC crosses PCM-worker to main; main owns and terminates the sibling inference worker explicitly. Keep at most one input window, one retained fallback copy and one selected result in that handoff. Cancellation closes both workers before owned-store cleanup.

Structured job events carry actual phases or model-loading bytes. Lazy neural code/model are requested only for isolation. Prefer a usable real WebGPU adapter when available, with one-thread CPU/WASM fallback and no cross-origin isolation dependency. Cause is repeated-session lifetime/collection behavior at this integration boundary; no native allocator leak is claimed without proof.

Replace reused model sessions with one explicitly owned inference worker per window. Test the same policy in Chromium before selecting it for both browsers. Preserve decoding/analysis/OLA in the PCM worker and put inference in a sibling worker owned by main processAudio through a bounded one-request RPC. Main terminates both workers on cancellation. Transfer one bounded window and one selected output, holding at most one inference request. Session teardown cannot depend on the PCM worker surviving or on native tensor collection between repeated calls. This updates the earlier accepted session lifetime after actual resource evidence, not by raising the budget. No second STFT implementation is introduced.

## Source preservation and replay correction

A real long-file voice-plus-music control found a maximum0.0030517578125 error concentrated at the original PCM edges. The stage was unnecessarily running the sinc resampler at an already-matching44100Hz. Bypass equal-rate conversion. More generally, preserve the requested music stream's original bandwidth by subtracting the reconstructed, original-rate voice from the original PCM. Both modes now request only vocals from the inference worker; the worker no longer exposes an unused music-mode API. Keep one original-rate OPFS spool, compute model-rate global statistics while writing it, and replay it for model-rate inference and original-rate subtraction. Decode still occurs once; replay is disk-backed bounded analysis, not a second decode.

Make replay capability explicit as PcmReplay.read() returning a fresh PcmStream over the immutable sealed File. A bare AsyncIterable can be a one-shot generator, so it did not encode the two-reader requirement. Existing normalization migrates to one read() call. Parent unit controls require voice+music to recover original source samples, not the accidentally twice-filtered reference, across rates/channels/source time and tail rounding. This accepted contract correction is scoped to checkpoint readers; storage ownership, headers and wire protocol remain unchanged. Subsample ranges that round to zero model-rate frames return a useful too-short error instead of a successful empty output.
